🌐 External Data Sources

Yahoo Finance (yfinance)
Real-time OHLCV data · 10 default tickers (AAPL, MSFT, GOOGL, AMZN, TSLA…)
NewsAPI
Financial headlines via REST API · 2 h cache TTL
RSS Feeds
Multiple financial news streams · URL-level deduplication

📥 Data Ingestion · finai/data/

stock_fetcher.py
4 h disk cache · retry logic (3×) · Parquet persistence
yfinance pickle cache
news_fetcher.py
RSS + NewsAPI fusion · 2 h cache · deduplication by URL hash
feedparser requests

🗄️ Storage

Cache Store
Pickle files with TTL awareness — eliminates redundant API calls
Raw Data Store
Parquet files — columnar OHLCV storage per ticker
Processed Feature Store
Scaled features + targets in Parquet — training-ready
Model Store
joblib-serialized XGBoost/LightGBM models + RobustScaler
ChromaDB Vector Store
Persistent cosine-similarity index for RAG semantic search

⚙️ Feature Engineering · finai/features/

technical_indicators.py
25+ indicators: RSI · MACD · Bollinger Bands · ATR · OBV · VWAP · Stochastic · ROC · SMA/EMA (10/20/50) · Historical Volatility
sentiment_features.py
FinBERT (HuggingFace Transformers) → VADER fallback · per-ticker daily aggregation
feature_pipeline.py
End-to-end orchestrator: fetch → indicators → sentiment → target label → scale → persist
RobustScaler
scikit-learn · fit on train split only · applied to test (prevents leakage)

🤖 ML Pipeline · finai/models/

XGBoost Classifier
Binary classification (price up/down) · class-weight balancing · early stopping on eval set
LightGBM Classifier
Binary classification · class-weight balancing · early stopping
Optuna Hyperparameter Tuning
30 trials per model · TPE sampler · maximises validation AUC
Soft-Voting Ensemble
Averages XGBoost + LightGBM class probabilities → final signal
TimeSeriesSplit CV
5 folds · no shuffle · preserves temporal order · zero future leakage
predictor.py
Inference pipeline → probability scores → BUY / HOLD / SELL signals

📊 MLOps · MLflow

MLflow Tracking Server (port 5000)
Logs params · metrics · feature importance · classification reports · model artifacts per run
MLflow Model Registry
Versioned model promotion: Staging → Production workflow

🧠 RAG Pipeline · finai/rag/

Sentence Transformers
all-MiniLM-L6-v2 · 384-dim dense embeddings for news documents
document_store.py
ChromaDB persistence · cosine similarity · URL deduplication · top-K retrieval
rag_chain.py
Retrieves top-5 context docs · assembles prompt · extracts citations from LLM response
LLM Backends
Primary: OpenAI GPT-4o-mini · Fallback: Anthropic Claude · Offline: context-only mode

🔍 Monitoring · finai/monitoring/

drift_detector.py
KS-test (p < 0.05 threshold) · PSI score (bins=10) · moderate >0.1, significant >0.2 · per-feature report
performance_tracker.py
Rolling accuracy snapshots · ROC-AUC over time · prediction history log
